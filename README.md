# Projeto base para aula de Acessibilidade

Algoritmo

1 - Criar dois botões na interface:

2 - Botão A+ para aumentar a fonte.

3 - Botão A- para diminuir a fonte.

4 - Adicionar acessibilidade aos botões:

5 - Inserir o atributo tabindex="0" em cada botão.

6 - Garantir navegação por teclado:

7 - ermitir que os botões sejam acessados usando a tecla Tab.

8 - Manter indicador de foco visível:

9 - Garantir que o outline (foco) apareça quando o botão estiver selecionado.

10 - Definir tamanho de fonte inicial da página.

11 - Criar evento de clique ou teclado para o botão A+:

12 - Quando acionado, aumentar o tamanho da fonte gradualmente.

13 - Criar evento de clique ou teclado para o botão A-:

14 - Quando acionado, diminuir o tamanho da fonte gradualmente.

15 - Atualizar o tamanho do texto da página após cada ação.

16 - Garantir compatibilidade com tecnologias assistivas.

17 - Testar a funcionalidade usando apenas o teclado (Tab + Enter/Espaço).
